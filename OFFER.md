# Fiktív ajánlat

A megadott PHP / webfejlesztői feladatot valós projektmunka keretében az alábbi feltételekkel vállalnám:

**Becsült fejlesztési idő:** 8 óra

Ez tartalmazza:

- a service osztály elkészítését,
- a bemeneti adatok validálását és normalizálását,
- a contact létrehozási / frissítési logika implementálását,
- az űrlapbeküldések mentésének előkészítését repository interfészeken keresztül,
- unit és integrációs tesztek elkészítését PHPUnit használatával,
- rövid README dokumentáció és tesztelési útmutató elkészítését.

**Nettó óradíj:** 12 000 Ft / óra

**Becsült nettó díj összesen:** 96 000 Ft

Az ajánlat a megadott specifikáció szerinti, önállóan tesztelhető PHP űrlapfeldolgozó szolgáltatás elkészítésére vonatkozik. Éles rendszerbe történő integráció, adatbázis-séma tervezés, migrációk, admin felület, e-mail értesítések vagy további üzleti validációk külön egyeztetés alapján kerülhetnek be a scope-ba.
